# Zalozenia projektu
Celem projektu jest zastosowanie modeli głębokich sieci neuronowych do ekstrakcji cech
wizualnych i tekstowych filmów, a następnie połączenie uzyskanych informacji w celu określenia
zgodności obiektów ze wskazanym profilem preferowanych cech. Wykonane zostanie zadanie
klasyfikacji obrazów oraz przetwarzanie języka naturalnego.
Należy wykorzystać dostępny jeden wspólny zbiór danych zawierający:
* plakaty filmowe,
* opisy filmów,
* informacje o gatunkach filmowych.
Głównym zadaniem jest zastosowanie wybranych modeli do ekstrakcji cech i interpretacja
uzyskanych wyników.
